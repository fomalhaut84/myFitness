## 1. 배경

v2.27.0 (#341) 에서 대시보드 **요약 카드**는 값의 출처를 밝히도록 바뀌었다 — 수면 SpO2 가 있으면 `SpO2`, 없어서 주간값으로 폴백하면 `SpO2 (주간)`.

그런데 같은 화면 아래쪽의 **월간 트렌드 차트** (`src/app/dashboard-client.tsx:310-316`) 는 데이터가 100% `DailySummary.avgSpo2` (주간 측정) 인데 제목이 그냥 `SpO2` 다.

```tsx
title={`SpO2${avgSpo2 !== null ? ` — 평균 ${avgSpo2}%` : ""}`}
data={monthlySpo2}   // page.tsx:183 — prisma.dailySummary 에서만 옴
```

결과: **같은 화면에서 `SpO2` 라는 동일 라벨이 두 가지 다른 측정 종류를 가리킨다.** 카드의 `SpO2` 는 (보통) 수면 측정값이고, 차트의 `SpO2` 는 항상 주간 측정값이다. #338 을 촉발한 혼선("앱에는 보이는데 리포트에는 없음")과 같은 계열의 용어 불일치다.

## 2. 목표

같은 화면에서 동일 라벨이 서로 다른 측정 종류를 가리키지 않게 한다.

## 3. 요구사항

- [x] F1: 월간 트렌드 차트 제목을 `SpO2 (주간)` 으로 정정
- [x] F2: 라벨 문자열을 `spo2CardLabel` 과 같은 소스에서 관리해 용어가 갈라지지 않게

## 4. 기술 설계

`src/lib/spo2-source.ts` 에 이미 `spo2CardLabel(source)` 이 있고 `"SpO2 (주간)"` 문자열을 만든다. 트렌드 차트는 source 가 항상 `"daily"` 로 고정이므로 `spo2CardLabel("daily")` 를 그대로 쓴다.

문자열을 차트 쪽에 다시 적으면 나중에 한쪽만 바뀌어 갈라진다 — #341 에서 포맷 헬퍼를 단일화한 것과 같은 이유.

```tsx
title={`${spo2CardLabel("daily")}${avgSpo2 !== null ? ` — 평균 ${avgSpo2}%` : ""}`}
```

### 데이터 소스는 바꾸지 않는다 (결정)

수면 SpO2 (`SleepRecord.avgSpO2`) 로 교체하거나 병기하는 안도 검토했으나 **이번 스코프에서 제외**한다.

- 프로젝트 정책상 수면 SpO2 가 기준값인 것은 맞지만, 주간 SpO2 추세도 그 자체로 의미가 있다 (측정 환경이 다를 뿐 무의미한 값이 아님)
- 차트를 추가하면 2열 그리드 배치가 바뀌어 대시보드 레이아웃 변경이 따라온다 — 라벨 불일치 해소라는 이번 목적과 별개의 작업
- 사용자 판단으로 라벨 정정만 채택

수면 SpO2 월간 추세가 필요해지면 별도 이슈로 다룬다.
