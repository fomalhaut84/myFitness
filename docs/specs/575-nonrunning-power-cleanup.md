## 1. 배경
러닝 파워 강도 (`Activity.power*`) 는 러닝 계열에만 계산한다. 이미 싱크된 러닝을 Garmin 에서 다른 종류로 바꾸면 재싱크 계산 결과는 null 인데, upsert update 는 "계산 불가면 기존 값 유지" 라 옛 러닝 파워 값이 남는다 → 강도 기준이 파워 (또는 자동 + 복약 · 더위) 이면 그 활동에 러닝 파워 강도가 읽힌다.

## 2. 요구사항
- [x] F1 싱크 update — 현재 종류가 러닝이 아니면 `power*` 4개를 비운다. 러닝인데 파워 · 역치파워가 없는 경우는 지금처럼 유지 (`powerColumnsForSync`)
- [x] F2 이미 남은 값 1회 정리 — 러닝 외 + `powerIntensityLabel` 있는 행을 비운다 (`clearNonRunningPowerIntensity` · 싱크 끝 · 백필 스크립트). 반복해도 안전
- [x] F3 심박 기준 값은 건드리지 않는다

- 로컬 DB: 활동 1건을 cycling 으로 바꿔 백필 → 파워 값만 비고 심박 라벨 유지 (확인 후 원복)
