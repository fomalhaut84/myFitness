## 1. 배경

`CompareTable` 푸터 "심박과 페이스는 낮을수록" 은 안정시 심박 · 페이스용 문구다. #442 로 2분 HRR (낙폭 · 클수록 빠른 회복) 이 선택 가능해지면서 기간 비교 뷰에서 안내가 결과와 반대로 읽힌다.

## 2. 요구사항

- [ ] F1 `HistoryMetricDef.betterWhen: "lower" | "higher" | "none"` — 지표 정의에 방향. 안정시 심박 · 페이스(젖산역치 페이스) · 스트레스 · 체중 = lower / 러닝 거리 · 횟수 · HRR · 수면 점수 · HRV · VO2max = higher / 걸음 · 칼로리 (활성 · 밸런스 · 섭취) · 러닝 시간 = none.
- [ ] F2 순수 함수 `compareDirectionNote(selected)` (`compare.ts`) — 선택 지표의 방향 한 줄. 푸터 = 일반 문장 ("색을 넣지 않는다 — 지표마다 방향이 다르다") + 이 한 줄 + (조건부) 월평균 안내.
- [ ] F3 `CompareTable` 은 `directionNote` prop 으로 받는다 (컴포넌트 안에서 지표 정의를 읽지 않는다).
- [ ] F4 vitest — `compareDirectionNote` 세 방향 · 모든 지표에 `betterWhen` 이 있음 (타입이 강제).
