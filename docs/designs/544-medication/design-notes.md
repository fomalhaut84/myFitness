# 복약정보 디자인 노트 (#544)

시안: `preview.html` (상태 A~C). 스크린샷 `screenshots/desktop.png` · `mobile-375.png`.
**모든 약 이름 · 용량 · 기간은 가상** — 실재 제품명을 쓰지 않는다 (memory: 건강 데이터 public 노출 금지).

## 브리프

복약 화면을 여는 이유는 두 가지 — **"지금 뭘 먹고 있나"** 와 **"검진 수치가 바뀐 그 사이에 뭘 먹었나"**. 앞은 카드 몇 장, 뒤는 기간 막대와 검진 회차 눈금이 한 축에 있으면 된다.

## 제약

#527 · #532 화면 언어 그대로 (h1 24px · 카드 12px · Geist / 수치 · 날짜 Geist Mono · 판정 색 amber · red · 액센트 녹색). 종류 구분 색 두 개만 추가 — **처방 = indigo-300**, **영양제 = teal-300**. 판정 색 (amber · red) · 액센트 (녹색 = 검진) 와 겹치지 않게.

## 결정

### 탭
`/medical` 상단 **검진 · 복약** 탭 (`?tab=meds`). 검진 탭은 지금 화면 그대로. 헤더 버튼은 탭에 따라 "검진 기록 추가" / "복약 추가".

### 복용 중
카드 그리드 — 이름 · 종류/형태 배지 · 용량 · 횟수 · 처방처 · "YYYY-MM-DD 부터 · N년 N개월째" · 관련 검진 항목 칩 · **복용 종료 (오늘)** · 수정. 진행 중인 단기 복용은 **점선 테두리** + "N일 남음" (종료 버튼 없음 — 종료일이 이미 있다).

### 복용 기간 타임라인 — 이 화면의 강조
연 단위 축 하나에 장기 복용은 **가로 막대** (복용 중이면 오늘까지), 단기 복용은 한 줄에 모은 **점** ("단기 복용 N건"), 검진 회차는 **녹색 점선 눈금**. "이 검진 때 무엇을 먹고 있었나" 가 한눈에. 모바일은 카드 안 가로 스크롤 (축 최소 폭 640).

### 지난 복약
연도별 (종료 연도) 묶음 · 한 줄: 이름 · 배지 · 기간 (단기는 "N일") · 장기는 **다시 시작** (복사해 새 행).

### 폼
종류 · 복용 형태는 세그먼트 (종류에 따라 형태 기본값). 단기면 종료일 대신 **"N일분 → YYYY-MM-DD 까지"** (직접 날짜도 가능). 관련 검진 항목은 검색 칩 입력 — 장기에만 의미가 있다는 안내.

### 항목 추이 연결
다이얼로그 차트 아래 **관련 복약** 목록 (지정한 장기 복용 · 기간) + 이력 표에 **그때 먹던 약** 열: 장기는 관련 항목 + 기간, 단기는 검진일 앞 14일 안이면 회색 배지 ("N일 전까지"). 차트 음영은 없다 (x 축이 회차 순서).

## 구현 메모 (구현 후 갱신)
- 검진 회차 눈금은 inline `rgba(34,197,94,.6)` — `accent` 가 CSS 변수 색이라 tailwind 투명도 수식어 (`/45`) 가 먹지 않고, 1px 점선은 흐리면 회색으로 보인다.
- 복용 중 정렬: 장기 먼저 (시작일 순) → 진행 중 단기.
- 이력 표 "그때 먹던 약" 열은 배지가 하나라도 있을 때만 · 단기 배지는 "N일 전까지" / "검진일 복용".
- 관련 검진 항목 고르기: 카탈로그 섹션별 + "기록된 다른 항목" (검진에 기록된 카탈로그 밖 항목).
- 수정 화면에서 종류를 바꿔도 복용 형태는 바꾸지 않는다 (기본값은 새로 추가할 때만).
