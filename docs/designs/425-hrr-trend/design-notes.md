# `/insights` 패널 E "회복이 빨라졌나?" — 디자인 노트 (#425)

시안: `preview.html` (단일 파일 · 가짜 데이터 — 해마다 2분 HRR 이 조금씩 커지는 경향, 2023 은 표본 4건, 3% 는 종료 뒤 심박이 오른 음수). 스크린샷 `screenshots/desktop.png` · `mobile-360.png`.

## 브리프

#397 의 네 패널 아래에 붙는 다섯 번째 패널. 질문은 하나 — "달리기를 멈춘 뒤 심박이 떨어지는 속도가 해마다 빨라졌나". 데이터는 러닝 2,157건의 2분 HRR (`Activity.hrr2`, #418 의 곡선에서 승격).

## 제약

#397 패널 언어 그대로 — 질문 → 차트 → 답 (큰 숫자 하나 + 근거 표), 산점도의 YoY 색 규칙 (올해 심박 색 · 과거 회색 사다리), 레이스 = 속 빈 점, 연도 토글, 5건 미만 `—`, foot 한 줄. 새 색 · 새 컴포넌트 없음. 자유도를 쓴 곳은 **x 축이 날짜** 라는 점과 **연도 중앙값의 표시** 둘뿐.

## 결정

### x = 시간 (소수 연도) — 다른 패널과 달리 "언제" 가 질문이라서

효율 · 기온 패널은 두 값의 관계라 x 가 값이다. 이 패널의 질문은 시간의 변화라 x 가 시간이어야 하고, 연도 색 + 시간 축은 중복 같지만 그렇지 않다 — 색은 토글 단위 (한 해만 켜서 보기), 축은 그 해 안의 분포 (계절 · 훈련 블록) 를 보여 준다. 눈금은 정수 연도만.

### 연도 중앙값은 차트 안에 — 큰 속 빈 밝은 점

표만 있으면 "빨라졌나" 를 눈으로 못 읽는다. 각 해의 한가운데 (`year + 0.5`) 에 **밝은 색 큰 속 빈 점** 하나가 그 해의 중앙값. 7개 점이 계단처럼 올라가면 답이 보인다. 이것이 이 패널의 굵은 표현 — 러닝 점은 작고 투명 (0.7), 중앙값 점만 밝다. 레이스의 작은 속 빈 점과는 크기 · 색으로 구분되고 범례에 둘 다 적는다.
- 5건 미만인 해 (시안의 2023) 는 중앙값 점을 그리지 않는다 — 표의 `—` 와 같은 규칙.

### 0 선 — 음수는 숨기지 않는다

종료 뒤 심박이 오른 러닝 (`hrr2 < 0`) 은 쿨다운 없이 멈춘 것이거나 종료 시각이 어긋난 것 (#418 각주와 동일). 0 에 가는 기준선을 두고 foot 에 한 줄. 필터로 빼면 중앙값이 좋아 보이게 왜곡된다.

### 답 = 중앙값 차 하나

"올해 vs 첫 해 +N bpm" — 효율 패널의 규칙 (마지막 유효 해가 올해가 아닐 수 있다 → "올해" 로 단언하지 않는다). 캡션에 두 해의 원값. 표는 연도 열 전부 (러닝이 있는 해), n 병기.

### 평균이 아니라 중앙값 — foot 에 이유

인터벌 · 레이스처럼 고심박에서 멈춘 러닝은 HRR 이 크다 (떨어질 여지가 크다). 평균은 이런 러닝 비율에 끌려간다. 강도별 분리는 후속 — 이번엔 중앙값으로 버틴다고 foot 에 적는다.

## 구현 시 시안과 달라지는 것

- `InsightScatter` 재사용 — x 는 소수 연도 (`yearFraction(ymd)`), `AxisFormat "year"` + 명시 눈금 (`x.ticks` 신설). 중앙값은 계열 하나 (`id: "median"`, 밝은 색, `hollow`, 반지름은 컴포넌트에 `size` 옵션 추가 또는 hollow 클래스 재사용 — 구현 시 판단). 중앙값 점은 클릭 대상이 아니다 (`href: null`).
- 0 기준선은 `ReferenceLine y={0}` (`pointerEvents: none`).
- 차트 높이 고정 (데스크톱 320 · 모바일 220). 시안 SVG 는 viewBox 축소라 폰에서 글자가 작다 — 구현에서는 해당 없음.
- 툴팁: 날짜 · `hrr2` · 거리 · 레이스 → 클릭 → 활동 상세 (기존 산점도 규칙).
- 백필 전에는 빈 상태 문구 ("종료 후 심박이 계산된 러닝이 없습니다").

## 접근성 · 품질 바닥

연도 토글 `aria-pressed` · 차트 `role="img"` + 표 · 판독값이 같은 정보를 글자로 · 색만으로 구분하지 않음 (중앙값 = 크기 + 속 빈 + 범례 · 레이스 = 속 빈 작은 점) · 모션 없음 · 360px 가로 넘침 없음 (CDP 측정).

## 사용자 확인이 필요한 결정

1. **x 축 = 시간** (다른 패널과 다름).
2. **연도 중앙값을 차트 안 큰 속 빈 점으로**.
3. **음수 (종료 뒤 상승) 를 필터하지 않고 0 선으로 보임**.
4. **답은 중앙값 차 하나** (평균 아님).
