# 건강 기록 — 검진 이력 디자인 노트 (#527)

시안: `preview.html` (단일 파일 · 상태 A~D · 행 클릭 시 항목 추이 다이얼로그). 스크린샷 `screenshots/desktop.png` · `mobile-375.png`.
**모든 값은 가상 데이터** — 회차 날짜 · 기관명 · 수치 · 판독문 전부 지어낸 것 (memory: 건강 데이터 public 노출 금지).

## 브리프

검진은 2년에 한 번, 화면을 여는 이유는 두 가지다 — **"지난번보다 뭐가 달라졌나"** 와 **"다시 받아야 할 검사가 있나"**. 항목은 수십 개지만 볼 것은 몇 개뿐이라, 화면은 그 몇 개를 먼저 꺼내고 나머지는 조용한 표로 둔다.

## 제약

기존 앱 언어 그대로 — h1 24px · 카드 12px 라운드 · 1px 보더 · Geist / 수치는 Geist Mono · 다크 토큰 (`--card #161616` 등). 판정 색은 앱에서 이미 쓰는 두 단계: **주의 = amber-300**, **이상 = red-400** (배경은 `*-900/40`). 액센트 녹색은 주 버튼 · 선택 회차 점 · 기준범위 띠에만.

## 결정

### 범위 막대 — 이 화면의 유일한 강조

결과 행마다 150px 막대: 기준범위 녹색 띠 + **직전 값 (빈 점) → 이번 값 (채운 점, 판정 색)**. 숫자를 읽기 전에 "범위 안 어디쯤 · 어느 쪽으로 움직였나" 가 보인다. 정성 결과 (요단백 · 영상) 는 막대 없이 배지.
- 막대 축은 **행마다 독립** (그 항목의 기준범위 · 두 값으로 맞춤) — 행끼리 위치를 비교하는 용도가 아니다.
- **하한 0 인 범위 (`0-129` 등) 는 '하한 없음' 으로 그린다.** 0 까지 축을 늘리면 띠가 막대 전체를 덮고 값 차이가 묻혔다 (1차 시안에서 확인). 추이 차트도 같은 규칙 + 축 하한 0 clamp.
- 스크린리더: `aria-label` 로 "기준범위 … 에서 이번 값 …, 직전 …".

### 기관 판정을 그대로

결과지 색 (기관 판정 2단계) 을 주의 / 이상으로 옮기고, 화면은 범위로 다시 판정하지 않는다 (스펙 §3-3). 판정이 없는 입력만 "자동" (범위 계산 · 정상 / 이상).

### 레이아웃

```
┌ 건강 기록 ─────────────────────── [검진 기록 추가] ┐
│ ┌회차 타임라인┐  ┌ 2025-06-11 검진          [수정] ┐ │
│ │● 2025-06-11 │  │ 종합 소견 + 확인할 항목 카드     │ │
│ │○ 2023-05-30 │  ├ 섹션: 항목 | 결과 | 막대 | 기준 | 직전 대비 │
│ │○ …          │  │ …                               │ │
│ └─────────────┘  │ 영상: 배지 + 판독문 펼침 + 추적검사│ │
│ ┌다가오는 추적검사┐                                   │
```
- 회차는 날짜 순서라 **세로 타임라인** (점 · 선). 모바일은 가로 스크롤 칩.
- **확인할 항목**: 그 회차에서 주의 · 이상인 수치 항목만 카드로 위에 — 값 · 직전 대비. 누르면 항목 추이.
- **다가오는 추적검사**: `followUpDue` 오름차순, 60일 이내 amber, 지난 것 red ("16일 지남"). 판독문 권고 원문과 원 회차를 아래 줄에.
- 섹션 표 열 폭은 `table-layout: fixed` 로 통일 — 섹션이 바뀌어도 막대가 같은 x 에 선다.

### 항목 추이 (B)

행 · 카드 클릭 → 데스크톱 다이얼로그 / 모바일 바텀시트. 수치: 회차별 선 + 기준범위 띠 (최근 회차 기준) + 판정 색 점 + 아래 이력 표 (검진일 · 결과 · 기준범위 · 기관). **단위가 다른 회차는 빈 점 + 경고 문장** ("값을 직접 비교하지 마세요") — 단위 변환은 하지 않는다 (스펙 §9). 정성: 회차별 배지 줄.

### 입력 폼 (C)

회차 헤더 (검진일 · 기관 · 종류) + 섹션별 접이식. 행 = 항목 (단위 표시) · 결과 · **기준범위 원문** · 판정 (자동 / 정상 / 주의 / 이상). 기준범위를 입력하면 바로 아래 해석 결과 ("하한 0 · 상한 199" / "정성 기준" / 못 읽으면 amber "원문 그대로 저장"). 섹션 요약에 입력 건수. 빈칸 = 미시행 (저장 안 함). "항목 직접 추가" 로 카탈로그 밖 항목.

### 빈 상태 (D)

설명 한 문장 + "검진 기록 추가". 결과지 불러오기 (M18-2) 는 아직 없으니 버튼 대신 흐린 안내 한 줄.

### 모바일 (375)

표 → 행마다 2줄 (이름 · 결과 / 막대 220px / 직전 대비). 기준범위 열은 숨기고 추이 화면에서 본다. 확인할 항목 카드는 2열.

## 구현 메모
- 범위 막대 · 추이 차트는 SVG 직접 (막대는 행 수가 많아 Recharts 인스턴스 대신). 추이 차트는 기존 Recharts 로 해도 됨 — 띠는 `ReferenceArea` (memory: Recharts 기본값 함정 — `allowDataOverflow` · pointerEvents).
