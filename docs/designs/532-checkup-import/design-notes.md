# 결과지 가져오기 디자인 노트 (#532)

시안: `preview.html` (단일 파일 · 상태 A~D · 회차 탭 · 포함 체크 동작). 스크린샷 `screenshots/desktop.png` · `mobile-375.png`.
**모든 값은 가상 데이터** — 항목명 · 수치 · 날짜 · 기관명 · 판독문 전부 지어낸 것 (memory: 건강 데이터 public 노출 금지).

## 브리프

결과지 한 장은 **금회 + 과거결과 열의 여러 회차**를 담는다. 사용자가 할 일은 "읽은 게 맞나" 확인뿐이라, 화면은 (1) 회차가 어떻게 나뉘었는지 (2) 무엇이 새로 들어가고 무엇이 그대로인지 (3) 손봐야 할 행이 어디인지만 드러낸다.

## 제약

#527 화면 언어 그대로 — h1 24px · 카드 12px 라운드 · Geist / 수치 Geist Mono · 판정 색 주의 amber-300 · 이상 red-400 · 액센트 녹색. 새 색은 **매칭 확인용 파랑 (blue-300 · 배경 blue-900/35)** 하나 — 판정 색과 겹치지 않게.

## 결정

### 회차 탭 — 이 화면의 축
확인 화면 맨 위에 회차 탭: 날짜 · `새 회차` / `기존 회차` 배지 · 행 수 (기존 회차는 `추가 · 다름 · 같음` 건수). 한 결과지가 여러 회차로 갈라진다는 사실을 먼저 보여 준다. 금회 탭은 검진일을 입력하기 전까지 "금회 (검진일 입력)".

### 행 상태
| 상태 | 배지 | 기본 포함 |
|---|---|---|
| 새 항목 | 녹색 `새 항목` | ✅ |
| 이미 있음 · 같은 값 | 흐린 `같은 값 · 이미 있음` | ❌ (흐리게) |
| 이미 있음 · 값 다름 | amber `값 다름` + "저장된 값 …" + `결과지 값으로 덮어쓰기` 체크 | ✅ 이지만 덮어쓰기는 꺼짐 → 체크 안 하면 건너뜀 |
| 같은 항목으로 중복 매칭 | red 문장 · 저장 막음 | ❌ |

### 매칭 표시
매칭 항목은 select (카탈로그 + "새 항목으로"). 이름이 정확히 일치하지 않은 매칭은 **파란 테두리**, 카탈로그에 없어 새 항목이 되는 행은 **점선 테두리**. 정확 일치는 평범한 테두리 — 눈이 갈 곳만 표시한다.

### 금회 헤더
검진일 (결과 화면에 없으면 amber 테두리 + "직접 입력하세요") · 기관 (읽었으면 채움) · 종류. 과거 회차는 금회의 기관 · 종류를 따른다 (탭 안내 문장).

### 추적 권고
판독문 아래에 권고 원문 + 예정일 입력. 예정일은 검진일 + 권고 기간으로 미리 채운다 (검진일 입력 전엔 "검진일 + 12개월" 표시).

### 진행 (B)
페이지 줄 = 썸네일 · 쪽 · 상태 (`항목 N개` 녹색 / `읽는 중…` 파랑 / `읽지 못함 · 다시 읽기` 빨강 / `대기`). 결과 표가 없는 쪽 (표지 · 안내문) 은 `항목 0개 — 결과 표가 없는 쪽` 으로 실패와 구분.

### 저장 바
화면 아래 고정: `새 회차 · 기존 회차에 추가 · 덮어쓰기 · 행` 건수 + 저장을 막는 이유 (빨강). 이유가 없을 때만 저장 활성.

### 완료 (D)
회차별 결과 한 줄 (`새 회차 · N개` / `기존 회차 · 추가 · 덮어쓰기 · 건너뜀`) + "금회 결과 보기" · "다른 결과지 가져오기".

### 모바일 (375)
표 → 행 카드: 체크 | 원문 항목명 → 매칭 select + 값 (오른쪽) → 기준범위 → 상태 · 판독문 (전체 폭). 저장 바는 그대로 고정.

### 진입점
`/medical` 헤더에 "결과지 가져오기" (보조 버튼, "검진 기록 추가" 옆) · 빈 상태 안내 한 줄을 버튼으로.

## 구현 메모 (구현 후 갱신)
- **날짜 확인 필요 회차** (사용자 결정 · 스펙 §3-6): 과거결과 열에서 날짜를 못 읽은 값은 결과지 표기 원문별 탭 (`날짜 확인 · <표기>` + amber `날짜 필요` 배지). 탭 안 amber 상자에 원문 표기 + 날짜 입력. 날짜를 넣거나 행을 모두 빼기 전엔 저장 바가 막는다.
- 상태 열 순서: 상태 배지 (새 항목 / 같은 값 / 값 다름) → 판정 배지 → 쪽 충돌 경고 → 판독문 (접힘) → 추적 권고 + 예정일 (`type=date`).
- 섹션 머리줄은 결과지 섹션 순서 그대로 (행 순서 = 추출 순서).
- 확인 화면 제목은 h2 (페이지 h1 "결과지 가져오기" 아래).
- 시안의 "새 회차" 표시는 날짜별 기존 회차를 불러온 뒤 결정 — 불러오는 동안 `확인 중` 배지 · 저장 막음.
