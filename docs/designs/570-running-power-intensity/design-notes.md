# 러닝 파워 강도 기준 디자인 노트 (#570-2)

시안: `preview.html` (상태 A ~ F). 스크린샷 `screenshots/desktop.png` · `mobile-375.png` (375px iframe — 오른쪽 검은 영역은 캡처 여백).
**수치는 전부 가상** (역치파워 300 W · LTHR 165 bpm · 활동 수) — memory: 건강 데이터 public 노출 금지.

## 브리프

이 화면에서 사용자가 알아야 할 것은 셋 — **"내 역치파워가 얼마고 어디서 왔나"**, **"강도를 무엇으로 재고 있나"**, **"기준을 바꾸면 무엇이 바뀌나"**. 마지막이 가장 중요하다: 기준 변경은 지난 활동 전체의 강도 · 훈련 부하 · ACWR 이력을 다시 계산하는 일이다.

## 제약

기존 화면 언어 그대로 — h1 24px · 카드 12px · Geist / 수치 Geist Mono · 액센트 녹색 · **Garmin 자동 = blue 배지 · 수동 = amber 배지** (`garmin-sync-section.tsx` `SourceBadge`) · 존 색은 활동 상세 `ZONE_META` (회색 · 녹색 · 파랑 · 주황 · 빨강). 새 색은 **파워 기준 배지 = amber-400 계열 (배경 amber-500/14)** 하나 — 심박 기준 배지는 중립 회색. 파워가 "새 기준" 이라는 점만 표시하고 경고처럼 보이지 않게 채도를 낮췄다.

## 결정

### 위치
`/settings/profile` 의 기존 "심박 Zone" 섹션 아래에 **러닝 파워** · **강도 평가 기준** 두 카드. 역치파워 입력은 기존 프로필 폼 (저장 버튼) 에 들어가고, **강도 평가 기준은 폼 밖 별도 카드 · 자체 버튼** — 전체 재계산을 일으키므로 다른 필드 저장에 섞이지 않게.

### 러닝 파워 카드 (A · C)
- 한 줄: 역치파워 · 출처 배지 · 값 · 감지 시각 (`garmin-sync-section` 의 `MetricSourceRow` 와 같은 배열). 수동이면 Garmin 값을 amber 로 병기 + **Garmin 자동으로** (기존 문구 그대로).
- **존 자 (ruler)** — 이 시안의 강조. Z1~Z5 를 W 경계 눈금과 함께 한 줄 막대로. 폭은 W 구간 비례 (Z5 는 상한이 없어 고정 폭). 195 W 미만 구간은 넣지 않는다 (막대 절반을 차지해 존이 눌려 보였다 — 1차 시안에서 뺌).
- 입력 필드: `역치파워 (W)` · 50~1000 · 힌트에 "수동으로 넣으면 싱크가 덮어쓰지 않는다" + 계산된 Z4 범위.

### 강도 평가 기준 (A · D)
- 라디오 카드 3개 (모바일 세로). 각 카드는 이름 + 한 줄 설명 — **파워는 "파워 없는 활동은 비워 둔다"**, 자동은 "파워 있으면 파워, 없으면 심박". 현재 값에 "사용 중" 표시, 고른 값은 녹색 테두리.
- 바로 아래 **결과 안내** (왼쪽 선): 지난 활동 전체 · 훈련 부하 · ACWR 이 다시 계산되고, Garmin 원본은 그대로라 되돌릴 수 있다.
- 버튼은 동작 이름 그대로 "**자동으로 바꾸기**" (고른 값에 따라 문구가 바뀐다) · 취소. 사용 중 값을 고르면 버튼 비활성.
- 파워 · 자동인데 역치파워가 없으면 (D) amber 안내 — 존 분포는 나오지만 보정이 빠진다는 사실 + 할 일 (값 입력 또는 다음 싱크).

### 결과 (B)
- 성공: "기준을 자동으로 바꿨습니다. 활동 N건 중 M건의 강도를 다시 계산했습니다." (API `recomputed` · 전체 수는 응답에 추가 — 570-2 구현 시 `recomputeTotal`)
- 실패: 무엇이 저장됐고 무엇이 안 됐는지 + **다시 계산** 버튼 (API `recomputeIntensity: true`). 사과하지 않는다.

### 활동 상세 강도 분석 (E)
- 카드 상단에 **기준 배지** (파워 기준 / 심박 기준) + 그 기준의 역치 (파워면 정규화 파워 병기).
- 존 목록에 경계 범위 열 추가 (W 또는 bpm) — 같은 Z4 라도 무엇으로 쟀는지 보이게. 존 이름은 파워면 "템포", 심박이면 "에어로빅" (Z3 · 스펙 M3 과 같다).
- 파워 기준이면 아래 한 줄 "평균 심박 N bpm (LTHR 대비 N%) — 심박은 참고로만" — 심박이 낮게 나와도 강도 라벨이 왜 높은지 이해되게.
- 파워 기준에서 파워 없는 활동: 빈 상태 + 할 일 ("심박으로 보려면 기준을 자동으로").

### 인사이트 · 비교 표 (F)
- 제목 "HR Zone 분포" · "심박 존 1~5" → **"강도 존"** + 오른쪽에 기준별 건수 ("파워 38건 · 심박 12건"). 한 기준만이면 그 기준 이름만.
- 같은 코스 비교 표: 라벨 옆에 기준을 짧게 (파워 / 심박) — 기준이 다른 두 기록의 라벨을 같은 잣대로 오해하지 않게.

### 하지 않는 것
