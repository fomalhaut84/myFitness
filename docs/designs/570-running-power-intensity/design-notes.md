# 러닝 파워 강도 기준 디자인 노트 (#570-2)

시안: `preview.html` (상태 A ~ F). 스크린샷 `screenshots/desktop.png` · `mobile-375.png` (375px iframe — 오른쪽 검은 영역은 캡처 여백).
**수치는 전부 가상** (역치파워 300 W · LTHR 165 bpm · 활동 수) — memory: 건강 데이터 public 노출 금지.

## 브리프

이 화면에서 사용자가 알아야 할 것은 셋 — **"내 역치파워가 얼마고 어디서 왔나"**, **"강도를 무엇으로 재고 있나"**, **"이 활동은 왜 그 기준인가"**. 기록은 심박 · 파워 두 가지로 모두 저장되고 (스펙 §2-1), 기준은 읽는 쪽만 바꾼다 — 되돌릴 수 있다는 점을 숨기지 않는다.

## 제약

기존 화면 언어 그대로 — h1 24px · 카드 12px · Geist / 수치 Geist Mono · 액센트 녹색 · **Garmin 자동 = blue 배지 · 수동 = amber 배지** (`garmin-sync-section.tsx` `SourceBadge`) · 존 색은 활동 상세 `ZONE_META` (회색 · 녹색 · 파랑 · 주황 · 빨강). 새 색은 **파워 기준 배지 = amber-400 계열 (배경 amber-500/14)** 하나 — 심박 기준 배지는 중립 회색. 파워가 "새 기준" 이라는 점만 표시하고 경고처럼 보이지 않게 채도를 낮췄다.
**파워 존 색은 번호가 아니라 의미로** — 파워 존은 심박 존보다 한 칸 위 (파워 Z1 이지 = 심박 Z2 · 파워 Z3 역치 = 심박 Z4) 라, 파워 Z1 녹색 · Z2 파랑 · Z3 주황 · Z4 빨강 · Z5 진한 빨강. 심박 · 파워 막대를 나란히 놓아도 같은 색 = 같은 강도 (1차 시안은 번호대로 칠해 역치가 파랑으로 보였다).

## 결정

### 위치
`/settings/profile` 의 Garmin 동기화 카드 바로 아래, 프로필 폼 위에 **러닝 파워** · **강도 평가 기준** 두 카드. 둘 다 **자체 저장 버튼** — 역치파워는 카드 안에서 입력 · 저장 (구현 중 변경: 프로필 폼에 넣으면 카드 안의 "Garmin 자동으로" 와 저장 경로가 둘로 갈린다), 강도 기준은 다른 필드 저장에 섞이지 않게.

### 러닝 파워 카드 (A · C)
- 한 줄: 역치파워 · 출처 배지 · 값 · 감지 시각 (`garmin-sync-section` 의 `MetricSourceRow` 와 같은 배열). 수동이면 Garmin 값을 amber 로 병기 + **Garmin 자동으로** (기존 문구 그대로).
- **존 자 (ruler)** — 이 시안의 강조. Z1~Z5 를 W 경계 눈금과 함께 한 줄 막대로. 폭은 W 구간 비례 (Z5 는 상한이 없어 고정 폭). 195 W 미만 구간은 넣지 않는다 (막대 절반을 차지해 존이 눌려 보였다 — 1차 시안에서 뺌).
- 입력 필드: `역치파워 (W)` · 50~1000 · 힌트에 "수동으로 넣으면 싱크가 덮어쓰지 않는다" + 계산된 Z4 범위.

### 강도 평가 기준 (A · D)
- 라디오 카드 3개 (모바일 세로). 각 카드는 이름 + 한 줄 설명 — 심박 "모든 활동을 심박으로" · **파워 "파워 기록이 있으면 파워, 없는 활동은 심박"** · **자동 "평소엔 심박, 약 · 더위로 심박이 흔들릴 때만 파워"**. 현재 값에 "사용 중", 고른 값은 녹색 테두리.
- 바로 아래 **결과 안내** (왼쪽 선): 기록은 두 기준 모두 저장돼 바뀌지 않고, 읽는 기준만 바뀐다 · 되돌릴 수 있다.
- 버튼 "**자동으로 바꾸기**" (고른 값에 따라 문구) · 취소. 별도 카드 · 별도 버튼인 이유: 프로필 폼 저장과 섞으면 무엇이 바뀌는지 흐려진다.
- 역치파워가 없으면 (D) amber 안내 — 지난 러닝의 파워 값을 아직 못 채워 그동안 심박으로 보인다 + 할 일 (값 입력 또는 다음 06:00 싱크).

### 결과 · 복약 (B)
- 성공 토스트: "기준을 자동으로 바꿨습니다. 지난 활동도 이 기준으로 보입니다." (재계산이 없어 실패 상태도 없다)
- 복약 폼에 **"심박에 영향을 주는 약"** 체크 + 한 줄 (자동 기준이 이 기간 러닝을 파워로 잰다). 약 이름 · 효능 판단은 하지 않는다 — 사용자가 표시.

### 활동 상세 강도 분석 (E)
- 카드 상단에 **기준 배지** (파워 기준 / 심박 기준) + **고른 이유** (심박 영향 복약 기간 · 더위 · 파워 기록 없음) + 역치 · 정규화 파워.
- 존 목록에 경계 범위 열 (W 또는 bpm). 파워 존 이름 = 이지 · 중강도 · 역치 · 인터벌 · 반복.
- **심박 · 파워 나란히** — 두 값이 다 있는 러닝에만. 두 막대 + 각 라벨 · 점수 + 평균 심박 한 줄 ("두 기준이 크게 다르면 심박이 평소와 다르게 반응한 날"). 모바일은 라벨 · 점수를 숨기고 막대만.
- 파워 기준이어도 파워 기록이 없는 활동은 심박 배지 + "파워 기록 없음" (빈 상태 없음 — 스펙 §2-2 폴백).

### 인사이트 · 비교 표 (F)
- 제목 "HR Zone 분포" · "심박 존 1~5" → **"강도 존"** + 오른쪽에 기준별 건수 ("파워 38건 · 심박 12건") + 설명에 현재 기준 규칙 한 줄. 한 기준만이면 그 기준 이름만.
- 같은 코스 비교 표: 라벨 옆에 기준을 짧게 (파워 / 심박) — 기준이 다른 두 기록의 라벨을 같은 잣대로 오해하지 않게.

### 하지 않는 것
- 존 경계 직접 편집 · `RunningAnalysis` "HR존 분포" 카드 변경 (평균 심박 기반 카드라 그대로 · U6).
