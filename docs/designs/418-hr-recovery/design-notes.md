# 종료 후 회복 (HRR) — 활동 상세 섹션 디자인 노트 (#418)

시안: `preview.html` (단일 파일 · 데이터는 로컬 실측 2026-04-05 트랙 러닝 종료 22:44:39 KST 와 그 변형 6 상태). 스크린샷 `screenshots/desktop.png` · `mobile-360.png`.

## 브리프

러닝 상세 페이지 "강도 분석" 아래에 들어가는 **섹션 하나**. 질문은 "달리기를 멈춘 뒤 심박이 얼마나 빨리 떨어지나". 데이터는 하루치 심박 시계열의 2분 샘플 7개 (−4 · −2 · 0 · +2 · +4 · +6 · +10 분) 와 거기서 나온 숫자 둘 (2분 HRR · 10분 낙차).

## 제약

활동 상세의 기존 언어 그대로 — 제목은 카드 밖 `h2`, 카드는 12px 라운드 · 1px 보더, 수치는 Geist Mono, 심박 색 `#f87171`. 새 색 · 새 서체 없음. 자유도를 쓴 곳은 곡선의 표현과 판독값의 구성뿐.

## 결정

### 2분 격자 위의 점 — 부드러운 곡선을 그리지 않는다

이 데이터는 7개 샘플이고 보간이 금지다 (PR #422 Codex P2). 스플라인 + 그라디언트 영역은 "연속 측정" 처럼 보이게 하는 거짓이라 쓰지 않는다. **점이 진실**이고 선은 점을 잇는 가는 안내선 (1.5px). 결측 점은 자리를 비우지 않고 **점선 빈 원**으로 남긴다 — 앱의 "기록 없음 = 뚫린 칸" 원칙 (#394). 선은 결측에서 끊긴다.
- 종료 이전 점 (−4 · −2) 은 회색 — 달리던 심박의 맥락일 뿐 회복이 아니다. 종료 이후 점만 심박 색.
- 종료 시점은 세로 점선 + 라벨 `종료 22:44`, 왼쪽 구간은 심박 색 5% 띠로 "달리는 중" 을 표시.

### 굵은 표현은 한 곳 — 0 → +2 낙차 라벨

곡선 위 +2 점 옆에 브래킷과 `↓16`. 화살표는 방향이 자명하게 — 판독값의 부호와 헷갈리지 않도록 숫자에 부호 대신 화살표를 쓴다. 이 라벨이 이 섹션에서 유일하게 밝은 색 (`--bright`) 글자다.

### 판독값 2칸 — HRR 은 양수 = 회복

`2분 HRR` (26px mono, 큰 숫자 하나) 와 `10분 낙차`. 둘 다 "종료 − N분 후" 라 **양수가 좋은 것**. 캡션에 `125 → 109 bpm` 처럼 두 원값을 적어 숫자의 출처를 보인다.
- 음수 (종료 뒤 심박이 오름) 는 부호 그대로 `−14` 로 보이고, 각주가 이유를 설명한다 (쿨다운 없이 정지 · 종료 시각 어긋남). 숨기지 않는다.
- 결측이면 `—`. `/insights` 의 "아직 답할 수 없음" 문구는 여기선 과하다 — 숫자 자리 하나가 비는 것이라 대시로 충분.

### 빈 상태 3구분

| 상태 | 표시 |
|---|---|
| 그 날 심박 레코드 없음 | 카드 안 한 줄 "이 날 심박 기록이 없습니다. 하루 심박이 싱크된 날의 러닝에서만 보입니다." |
| 레코드는 있으나 종료 후 유효 점 2개 미만 | "종료 후 샘플이 부족합니다. 워치를 바로 벗었을 수 있어요." |

섹션 자체를 숨기지 않는다 — 러닝이면 항상 자리가 있어, 왜 없는지가 보인다.

### 해상도 표기

`h2` 오른쪽에 작게 `2분 해상도`, 각주에 "하루 심박 기록의 2분 샘플 — 워치의 1분 HRR 과 다릅니다. 점은 ±60초 안의 가장 가까운 샘플." 워치 숫자와 다른 이유를 사용자가 묻기 전에 답한다.

## 구현 시 시안과 달라지는 것

- 차트는 Recharts `LineChart` (x = 숫자 축 `offsetMin`, `connectNulls={false}`, `ReferenceLine x={0}`, `ReferenceArea x1={-5} x2={0}`). 결측의 점선 빈 원과 낙차 브래킷은 `Customized` 또는 점 `shape` 로. 툴팁 커서는 `pointerEvents: none` (memory `feedback_recharts_defaults`).
- 차트 높이 고정 (170). 시안 SVG 는 viewBox 축소라 폰에서 글자가 작다 — 구현에서는 해당 없음.
- 종료 시각은 `formatTimeKST(endIso)`.
- 폰: 판독값 2칸이 가로 2열 (시안과 동일).

## 접근성 · 품질 바닥

차트 `role="img"` + `aria-label` · 판독값이 같은 정보를 글자로 (2분 HRR · 10분 낙차 · 캡션의 원값) · 색만으로 구분하지 않음 (종료 전 = 회색 점 · 결측 = 점선 원) · 모션 없음 · 360px 가로 넘침 없음 (CDP 측정 `scrollWidth = 360`).

## 사용자 확인이 필요한 결정

1. **점 + 안내선** (스플라인 · 영역 채움 아님).
2. **HRR 부호**: 양수 = 회복. 음수는 숨기지 않고 각주로 설명.
3. **판독값 2개** (2분 HRR · 10분 낙차) — 4분 · 6분 은 곡선에서만.
4. **빈 상태에서도 섹션을 숨기지 않음**.
